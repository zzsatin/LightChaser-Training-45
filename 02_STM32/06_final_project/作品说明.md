# 基于 STM32F103C8T6 的红外循迹 / 避障 / 遥控智能小车

## 1. 功能概述

以 STM32F103C8T6 为主控，用 L298N 驱动左右两个直流减速电机，配合红外循迹、红外避障和红外遥控模块，做出一台可以在三种工作模式间切换的智能小车。

主要功能：

- **红外循迹**：两路循迹传感器识别黑色引导线，自动直行、单侧压线修正、双线停车；
- **红外避障**：左右两路避障传感器检测前方障碍，单侧遮挡时向另一侧转向，两侧同时遮挡时先停车再原地右转；
- **红外遥控**：板载红外接收头解码 32 位遥控码，遥控器控制前进、后退、左转、右转、停止；
- **模式切换与状态显示**：按键在 1 / 2 / 3 三种模式间循环切换，共阳数码管实时显示当前模式编号；
- **调试输出**：串口 1 以 9600bps 输出遥控码值和运行信息，方便调试。

## 4. 实现思路

### 4.1 系统框图

```
  4×AA 电池（6V）
        │
        ├──────────────► L298N 电机驱动 ──► 左电机 / 右电机
        │                     ▲
        │            PB6~PB9（TIM4 四路 PWM）
        │                     │
 ┌──────┴─────────────────────┴───────────────────────┐
 │                 STM32F103C8T6                     │
 │   TIM4 PWM    GPIO 输入    EXTI 中断    USART1    │
 └───┬──────────────┬──────────────┬─────────────┬───┘
     │              │              │             │
  数码管        循迹 / 避障     红外接收      串口调试
 PA0~PA7   PB12/PB13、PA11/PA12    PA8        PA9/PA10
```

### 4.2 主循环与模式切换

程序用一个全局变量 `temp` 记录当前模式，`main()` 里不断轮询按键：

- 按下 PA15（`Key_GetNum()` 返回 1）→ `temp++`，超过 3 时回到 1；
- `switch (temp)` 进入对应模式：
  - 模式 1：`Robot_Traction()`，红外循迹；
  - 模式 2：`Robot_Avoidance()`，红外避障；
  - 模式 3：`Irscan()`，红外遥控解码；
- 每次切换都调用 `Digital_Display(temp)` 在数码管上显示模式编号。

电机部分用 TIM4 的四个通道产生 20kHz 的 PWM，`robot_speed(left1, left2, right1, right2)` 把占空比写入四个比较寄存器，再封装出前进、后退、左转、右转、原地旋转、刹车六个动作。

### 4.3 传感器与中断

- 循迹、避障模块都是数字量输出，GPIO 配置为上拉输入，主循环直接读取；
- 红外接收头接 PA8，配置为下降沿触发的外部中断（EXTI9_5），中断里用 20us 轮询测量高电平宽度完成解码；
- 串口 1 使用 9600-8-N-1，开启接收中断，并通过 `printf` 重定向打印调试信息；
- 中断优先级分组为 2 位抢占 + 2 位子优先级，红外中断优先级最高（0,1），串口 1 为（1,1）。

### 4.4 通信协议

**红外遥控（NEC 格式）**：接收头输出经内部反相后，用 20us 为单位统计高电平持续时间：

| 高电平宽度 | 判定 |
| --- | --- |
| 4.0 ~ 5.0ms（200~250 次） | 帧起始 |
| 1.2 ~ 1.8ms（60~90 次） | 数据位 1 |
| 0.2 ~ 1.0ms（10~50 次） | 数据位 0 |

连续解出 32 位后存入 `IR_Receivecode`，取高 8 位作为按键码。程序里约定的键值：

| 高 8 位 | 动作 |
| --- | --- |
| 0xB1 | 前进 2s |
| 0xD4 | 后退 2s |
| 0x91 | 原地左转 2s |
| 0xE1 | 原地右转 2s |
| 0x81 | 停止 |

**串口**：9600bps，8 数据位、无校验、1 停止位。主要输出 `红外接收码 %08X`、`buf[0] / buf[1]` 等调试信息，未定义上位机协议。

## 6. 遇到的问题与解决

| 问题 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| 下载后电机完全不转 | 程序像"死"了，按键无反应，电机没有声音 | PWM 初始化用 `for (Channel = TIM_CHANNEL_1; Channel <= TIM_CHANNEL_4; Channel++)` 遍历，但四个通道常量是 0/4/8/12，第二次循环就传入非法通道，HAL 返回错误并进入 `Error_Handler()` 死循环 | 改成用通道数组遍历；用 ST-Link 读 `uwTick`、TIM4 的 `CR1` / `CCER` 寄存器确认问题 |
| 循迹模式上电不动 | 数码管显示 1，电机不转 | 车被架空、传感器没有贴近地面，两路循迹都读到高电平，程序判定为"双侧压线"直接刹车 | 把车放到黑线/白色地面，调节循迹模块电位器；先用模式 2 验证电机 |
| PA15 按键没反应 | 读不到按键低电平 | PA15 默认是 JTDI，被 JTAG 占用 | SYS 里 Debug 选 Serial Wire，代码里调用 `__HAL_AFIO_REMAP_SWJ_NOJTAG()` |
| 延时函数不能沿用 | 改成 HAL 后微秒延时会导致 `HAL_Delay` 变慢、卡死 | 原延时函数直接改写 SysTick 寄存器，破坏了 HAL 的 1ms 时基 | 改用内核 DWT 周期计数器 `DWT->CYCCNT` 实现微秒延时 |
| `printf` 没有输出 | 串口收不到任何字符 | 没有实现 newlib 的输出重定向 | 在串口驱动里实现 `__io_putchar()`，`syscalls.c` 的 `_write()` 会调用它 |
| 串口中文乱码 | 中文提示显示为乱码 | 源文件是 UTF-8，串口助手按 GBK 解析 | 串口助手编码改为 UTF-8 |
| 链接时报回调重复定义 | 串口 1 和串口 3 都要用接收回调 | 两处都定义了 `HAL_UART_RxCpltCallback` | 只在 `Serial.c` 定义一次，串口 3 通过弱函数 `Uart3_RxCpltHook()` 分发 |

## 7. 测试结果

**编译与下载**

- STM32CubeIDE 编译：0 error、0 warning；
- ST-Link 下载：`Download verified successfully`，复位后运行正常。

**功能测试**

| 测试项 | 测试方法 | 结果 |
| --- | --- | --- |
| 模式切换 | 上电后按 PA15，观察数码管 | 1 → 2 → 3 → 1 循环，显示正确 |
| 电机 PWM | 用 ST-Link 读 TIM4 寄存器 | `CCER = 0x1111`，四通道输出使能；`CCR` 随速度设置变化 |
| 循迹 | 黑线跑道 | 直行、单侧压线修正、双线停车 |
| 避障 | 用手掌遮挡左 / 右 / 两侧 | 单侧遮挡向另一侧转 0.4s；两侧遮挡停车 0.4s 后原地右转 0.9s |
| 红外遥控 | 按遥控器方向键 | 对应动作执行，串口打印 32 位码值 |
| 串口输出 | USB-TTL + 串口助手 | 9600-8-N-1，UTF-8 编码下中文正常 |

**已知缺陷**

1. 电机是开环 PWM 调速，没有编码器，速度会随电池电压下降而变慢；
2. 避障距离由模块上的电位器决定，软件无法设置阈值；
3. 循迹对地面反光和传感器高度比较敏感，需要现场调节；
4. 模式 3（红外遥控）里解码是一个 `while(1)` 循环，进入后只能复位退出，不能按键切回其他模式；
5. 红外解码对强光和距离比较敏感，超出 5m 或阳光直射时可能误码。

## 8. 演示说明

**上电流程**

1. 把小车放在黑线跑道上（循迹模式），或者放在空旷地面（避障 / 遥控模式）；
2. 打开扩展板电源开关，数码管显示 `1`，进入循迹模式；
3. 按 PA15 切到 `2`：避障模式；再按切到 `3`：红外遥控模式；再按回到 `1`。

**演示步骤**

1. 循迹：把车放在黑线起点，车沿黑线行驶，偏离时自动修正；
2. 避障：用手或纸板挡在左侧 / 右侧传感器前，车向相反方向转向；两侧同时遮挡时停车后原地右转；
3. 遥控：按遥控器的方向键控制前进、后退、左转、右转、停止，串口助手可以看到接收码；
